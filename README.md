
# AI-Based Food Waste Prediction and Smart Donation Recommendation System

## 1. Project Overview

This project uses Machine Learning to predict food waste based on kitchen and food-related information.

It also recommends suitable donation centers for surplus food based on food category and donation capacity.

## 2. Objectives

- Predict food waste using Machine Learning.
- Analyze food waste patterns.
- Reduce unnecessary food waste.
- Recommend suitable donation centers.
- Provide an interactive dashboard using Streamlit.

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regressor
- Streamlit
- Joblib
- Matplotlib (if used)

## 4. Machine Learning Algorithm

Random Forest Regressor is used to predict the quantity of food waste in kilograms.

## 5. Project Modules

1. Data Collection
2. Data Preprocessing
3. Feature Engineering
4. Model Training
5. Food Waste Prediction
6. Smart Donation Recommendation
7. Data Visualization
8. Streamlit Deployment

## 6. How to Run the Project

Install the required libraries:

    python -m pip install -r requirements.txt

Run the Streamlit application:

    python -m streamlit run app.py

## 7. Expected Output

- Predicted food waste in kilograms.
- Food waste analytics dashboard.
- Food waste category charts.
- Food waste trend chart.
- Recommended donation centers.

## 8. Conclusion

This project demonstrates how Machine Learning can support food waste prediction and help identify potential donation centers for surplus food.
